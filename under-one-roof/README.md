# Under One Roof — تحت سقف واحد

لعبة مغامرات قصصية ثنائية الأبعاد بأسلوب Pixel Art، تدور أحداثها في قرية الصيد الخيالية **هرافنفيك** في آيسلندا عام 1887.
يتحكّم اللاعب في **غيديون آشفورد**، الشاب الفقير الذي يحاول إعالة أمه وأخته، حتى يعود ابن عمّه **إلياس** بثروة غامضة.

صُنعت اللعبة بمحرّك **Godot 4.3**، وكل رسوماتها وأصواتها أصلية ومولَّدة بالكود (راجع `tools/`).

## التشغيل

1. نزّل [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) (النسخة العادية، وليس .NET).
2. افتح Godot واختر **Import**، ثم اختر الملف `under-one-roof/project.godot`.
3. اضغط **F5** (أو زر ▶) للعب.

من سطر الأوامر:

```bash
godot --path under-one-roof            # تشغيل اللعبة
godot --path under-one-roof -e         # فتح المحرّر
```

## التحكم

| | لوحة المفاتيح | الهاتف |
|---|---|---|
| الحركة | الأسهم أو WASD | عصا التحكم يسار الشاشة |
| الركض | Shift | زر الرجل الراكض (تشغيل/إيقاف) |
| التفاعل / التحدث / متابعة الحوار | E أو المسافة أو Enter | زر اليد، أو المس الحوار |
| دفتر غيديون (المهام، الأدلة، الحقيبة، الحفظ) | J أو Esc | زر الكتاب، أو المس لوحة المهمة |
| استعمال غرض أو قراءته | — | المس الخانة في الشريط مرتين |

الأبواب تُفتح بمجرد المشي إليها. ويشير السهم الذهبي دائمًا إلى هدف المهمة الحالية.

## محتوى اللعبة

- **8 فصول كاملة** كما في وثيقة القصة: من «صباح رجل فقير» إلى «المواجهة الأخيرة»، ثم الخاتمة والمشهد الأخير.
- **عالم قابل للاستكشاف**: القرية والساحة والسوق والكنيسة والمقبرة والنُّزل والميناء والأرصفة والشلال والحقول، وضيعة إلياس، والتلال الشرقية، والمزرعة المهجورة، والحظيرة، وحطام السفينة. ولكل من البيت والنُّزل والمكتب وبيت المزرعة والحظيرة داخلٌ يمكن دخوله.
- **17 شخصية** لكل منها حوارات تتغيّر من فصل إلى آخر، فتعكس آراء أهل القرية في عائلة آشفورد.
- **6 مهام جانبية**: البوصلة الضائعة، وحلم الخيّاطة، ولوحات كلارا، وسرّ الحدّاد، ورسالة الكاهن، وحطام السفينة.
- **أعمال لكسب المال**: الصيد، وتقطيع الحطب، ونقل الصناديق، وجمع الأعشاب، والعمل في الحديقة، ومساعدة الحدّاد، وإطعام الأغنام. وفيها لعبة توقيت قصيرة.
- **متجر هنريك**: فانوس يضيء الليل، وحذاء يسرّع الحركة، وهدايا للعائلة، وسجّادة للبيت.
- **مقتنيات**: وثائق العائلة (اجمعها كلها لتفتح رسالة إضافية في النهاية)، وتذكارات القرية، والأصداف، والعملات.
- **دورة يوم وليل**، والنوم، والحفظ التلقائي في بداية كل فصل، والحفظ اليدوي من الدفتر.
- **واجهة مصمّمة للهاتف** مع أزرار لمس، وواجهة عربية كاملة.

## بنية المشروع

```
under-one-roof/
  project.godot          إعدادات المحرّك (640×360، وضع أفقي، Compatibility renderer)
  scenes/                title.tscn, main.tscn, player.tscn
  scripts/autoload/      game.gd (الحالة والحفظ)، director.gd (منفّذ القصة)، audio.gd
  scripts/world/world.gd يبني العالم من data/ (الأرض، والتصادمات، والأجسام، والأبواب، والشخصيات)
  scripts/actors/        player.gd, npc.gd
  scripts/ui/            hud, dialogue, touch_controls, journal, panels (قارئ، متجر، لعبة توقيت), fader, title
  data/story.gd          كل نص القصة: الشخصيات والمهام والحوارات والأحداث
  data/world.json        الأجسام والنقاط والمناطق (مولَّد)
  data/map.txt           شبكة التضاريس (مولَّدة)
  assets/                رسومات وأصوات مولَّدة + خطوط Cairo وLalezar (رخصة SIL OFL)
  tools/                 مولّدات الأصول بلغة Python
  tests/                 اختبارات آلية
```

### تعديل القصة

كل الحوارات والأحداث موجودة في `data/story.gd`. كل حدث قائمة من مداخل، وأول مدخل يتحقّق شرطه (`"if"`) هو الذي يُنفَّذ:

```gdscript
"bjorn": [
    {"if": ["item:compass", "!q_compass_done"],
     "lines": [["bjorn", "بوصلتي! أين وجدتها؟"]],
     "do": [["take", "compass"], ["give", "photograph"], ["set", "q_compass_done"]]},
    ...
]
```

### إعادة توليد الرسومات والخريطة

```bash
pip install pillow numpy
python3 tools/build_assets.py                   # يولّد الصور والأصوات والخريطة
python3 tools/preview_world.py /tmp/map.png     # صورة كاملة للخريطة للمعاينة
godot --headless --path . --import              # إعادة استيراد الأصول في Godot
```

## الاختبارات

```bash
godot --headless --path . res://tests/check_scripts.tscn   # تحميل كل السكربتات والمشاهد
godot --headless --path . res://tests/playthrough.tscn     # يلعب القصة كاملة آليًا (+1200 فحص)
godot --headless --path . res://tests/controls.tscn        # حركة وتصادمات وأبواب وأزرار بالوقت الحقيقي
xvfb-run godot --path . res://tests/shots.tscn -- /tmp/shots  # لقطات شاشة
```

## التصدير للهاتف

من المحرّر: **Project → Export → Add → Android** (يتطلّب Android SDK وJDK)، أو **Web** للتشغيل في المتصفح.
المشروع مضبوط على الوضع الأفقي وعلى العارض المتوافق مع الهواتف (GL Compatibility).
