# Rotten Crown

لعبة رعب نفسي ودارك فانتازي قوطية من منظور الشخص الأول، ثلاثية الأبعاد بأسلوب البيكسل آرت، لأجهزة Android، على محرك **Godot 4.4**.

> مملكة ڤالدرون احتفلت بانتصارها على لوريس، فلعنها أليستر أثناء الحفل.
> الفارس نام تحت القمر خارج الأسوار، واستيقظ على صمتٍ تام.

**الحالة:** المرحلة 1 من 8 — الهيكل ومشهد الاختبار البصري. راجع [`docs/ROADMAP.md`](docs/ROADMAP.md).

## 📱 العب على هاتفك (من المتصفح)

**الرابط:** https://mahmoud70004-debug.github.io/godot-mcp/

افتحه في Chrome أو Safari على الهاتف، ثم أدِر الهاتف للوضع الأفقي. من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية"** لتفتح اللعبة كتطبيق بملء الشاشة. كل مرحلة جديدة تُنشر على الرابط نفسه.

**رابط بديل (يعمل دون أي إعداد):** `https://raw.githack.com/mahmoud70004-debug/godot-mcp/<COMMIT_SHA>/docs/index.html`
استبدل `<COMMIT_SHA>` برقم آخر commit يحتوي على مجلد `docs/`. ستظهر صفحة تنبيه من githack عند الفتح، فاضغط **Open the page**.

> النسخة على المتصفح تستخدم مُصيِّر **Compatibility** (أي WebGL 2)، لأنه الوحيد الذي تدعمه المتصفحات. لذلك قد تختلف الإضاءة قليلاً عن نسخة Android الأصلية التي تستخدم مُصيِّر Mobile.

### النشر (للمطوّر)
```bash
export GODOT=$(tools/setup_godot.sh)    # ينزّل Godot 4.4.1 وقوالب الويب فقط (~70MB)
tools/publish_web.sh                    # تصدير، ثم نسخ إلى ../docs (المجلد الذي يخدمه GitHub Pages)
(cd ../docs && python3 -m http.server 8766 &) && node tools/web_smoke_test.cjs http://localhost:8766/index.html build/smoke
```
أضف `?debug=1` للرابط لعرض FPS وحالة اللمس على الشاشة، وهذا مفيد عند الإبلاغ عن خلل.

يحاكي `web_smoke_test.cjs` هاتفاً أفقياً يعمل باللمس في Chromium: يبدأ اللعبة، ويمشي عبر البوابة، وينظر حوله، ويهاجم، ويفتح الحقيبة، ويحفظ صوراً للشاشة. ويفشل إذا ظهر أي خطأ من المحرك.

## التشغيل

1. ثبّت **Godot 4.4** أو أحدث (النسخة القياسية، لا .NET).
2. افتح Godot، ثم **Import**، واختر `rotten-crown/project.godot`.
3. عند أول فتح سيستورد Godot الملفات وينشئ مجلد `.godot/` (هذا طبيعي، والمجلد في `.gitignore`).
4. اضغط **F5**: تبدأ القائمة الرئيسية، ثم **Wake Up**.
   - لتجربة المشهد مباشرة: افتح `src/levels/test/visual_test.tscn` واضغط **F6**.

### التحكم
| | الهاتف (أفقي) | الحاسوب (للاختبار) | Gamepad |
|---|---|---|---|
| حركة | الذراع اليسرى الثابتة | WASD / الأسهم | العصا اليسرى |
| نظر | سحب النصف الأيمن | الفأرة | العصا اليمنى |
| هجوم | ATK | زر الفأرة الأيسر / J | RB |
| صدّ | GRD (مع الاستمرار) | K / Shift | LB |
| تفاعل | USE (يظهر عند الحاجة) | E | A |
| الحقيبة | BAG | I / Tab | Y |
| إيقاف | II | Esc | Start |

لمعاينة أدوات اللمس على الحاسوب: فعّل **Preview touch controls** في القائمة الرئيسية، ثم شغّل Godot مع خيار *Emulate Touch From Mouse* (Project Settings ← Input Devices).

## ماذا تختبر في مشهد الاختبار
0. **Wake Up** يشغّل المشهد الافتتاحي (احتفال ليلة النصر). يمكنك تخطّيه بـ **SKIP**.
1. تستيقظ في **سهول ضوء القمر** بجانب فانوسك الساقط. التقط **الدعوة الممزّقة**.
2. ادخل من **البوابة المكسورة** فتظهر بطاقة عنوان "The Outer Ward".
3. في **الوليمة**: Hollow نائم وظهره لك. اقترب لترى رأسه يلتفت قبل جسده.
4. **البئر**: الـ Mourner يتجمّد حين تنظر إليه. انظر بعيداً... ثم عد.
5. **الحدادة** (يمين): التقط **فأس الحطّاب**، وجهّزه من الحقيبة، وقارن سرعته بالسيف.
6. داخل البيت الأيسر الأول: **طحلب القبور** للعلاج. وعلى حافة البئر: **عين القديسة أورسا** (+20 صحة ما دمت تحملها).

## التحقق دون فتح المحرك
```bash
python3 tools/validate_project.py         # مسارات res:// ومعرّفات الموارد و NodePaths و $/% وخصائص .tres
pip install "gdtoolkit==4.*" && gdparse $(find src -name "*.gd") && gdlint src
```

## التصدير إلى Android
1. Editor ← Manage Export Templates، ثم نزّل القوالب.
2. Editor Settings ← Export ← Android: حدّد Android SDK و Debug Keystore.
3. Project ← Export ← **Android** (الإعداد جاهز: arm64، ووضع ملء الشاشة، والاتجاه الأفقي)، ثم Export Project.
